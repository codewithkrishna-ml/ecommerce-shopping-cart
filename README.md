# E-Commerce Shopping Cart System 🛒🛍️

A robust and scalable E-Commerce Shopping Cart simulation system built in Python using **Object-Oriented Programming (OOP)** principles. This application models a real-world online shopping experience, from browsing a product catalog to generating a final checkout invoice.

## ✨ Key Features

*   **Product Catalog Management:** Browse a dynamically managed inventory of items with details like Price, Category, and Stock Status.
*   **Dynamic Cart Operations:** Add items to the cart, update product quantities, or remove items seamlessly with real-time recalculations.
*   **Stock Validation:** Automatically checks inventory levels before allowing a user to add an item to their cart, preventing overselling.
*   **Discount & Promo System:** Supports coupon code verification or automatic percentage discounts on specific conditions.
*   **Automated Checkout & Invoice Generation:** Calculates total prices, applies simulated taxes/discounts, and prints a structured final bill.

---

## 🛠️ OOP Concepts Implemented

This project focuses heavily on structured data design and component interaction:
*   **Classes & Objects:** Structured around clean entities like `Product`, `ShoppingCart`, `Customer`, and `Order`.
*   **Composition:** The `ShoppingCart` class manages a collection of `Product` objects, cleanly demonstrating how objects interact and hold references to one another.
*   **Encapsulation:** Protects internal pricing models, customer details, and cart totals using private variables, modifying them only through authorized methods.
